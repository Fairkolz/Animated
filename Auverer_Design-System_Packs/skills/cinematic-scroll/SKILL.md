# Cinematic Scroll Skill — GSAP + ScrollTrigger

Use for narrative, experiential pages where scrolling controls a visual sequence.

Techniques:
- pinned sections
- scrubbed timelines
- layered parallax
- product/object travel
- scale/rotation transitions
- image/video sequencing
- horizontal movement
- section choreography
- camera-like transitions

Before implementation, define the timeline from 0% to 100% scroll progress.

Use GSAP context/cleanup correctly in React.

Provide responsive and reduced-motion fallbacks.

Do not create cinematic scrolling merely for spectacle.
