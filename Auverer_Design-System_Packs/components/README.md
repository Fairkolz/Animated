# Reusable Component Foundation

Components are intentionally themeable. Do not hard-code one brand into the reusable layer.

Suggested primitives:
- Button
- Link
- Input
- Select
- Textarea
- Badge
- Card
- Modal
- Accordion
- Tabs
- Tooltip
- Navbar
- Footer
- Section
- Container

Project-specific compositions should be built on top of these primitives.
