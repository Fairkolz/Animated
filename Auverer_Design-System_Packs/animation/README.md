# Reusable Animation Pattern Library

Animation patterns are recipes, not one-size-fits-all code.

Patterns to build/reuse:
- reveal
- stagger
- hover micro-interaction
- page transition
- pinned scroll sequence
- parallax layers
- product travel path
- horizontal scroll
- image mask reveal
- text split/reveal

Every pattern should define:
- trigger
- start state
- end state
- duration
- easing
- responsive fallback
- reduced-motion fallback
- recommended tool

Tool recommendation:
- CSS/Motion → simple UI interaction
- Motion → React component animation
- GSAP → complex timeline
- ScrollTrigger → scroll choreography
- Lenis → smooth scrolling
