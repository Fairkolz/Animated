# Dependency Guide

Next.js + React
→ application framework

Tailwind CSS
→ styling system

Motion (formerly Framer Motion)
→ React/UI animation, layout, gestures and transitions

GSAP
→ complex animation timelines

GSAP ScrollTrigger
→ scroll-driven, pinned and scrubbed animation

Lenis
→ smooth scrolling

Three.js / React Three Fiber / Drei
→ optional 3D/WebGL experiences

Keep npm dependencies project-local. Do not globally install project libraries just to make every project depend on them.
