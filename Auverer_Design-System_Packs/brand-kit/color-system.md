# Semantic Color System

Define colors by role, not by component.

Recommended roles:
- brand-primary
- brand-secondary
- accent
- surface-background
- surface-elevated
- text-primary
- text-secondary
- text-muted
- text-inverse
- border-default
- border-strong
- success
- warning
- error
- info

Example:
`primary-action` should consume a semantic role. A SaaS project may make it blue, a barber project black, and a luxury project gold.

This keeps reusable components themeable.
