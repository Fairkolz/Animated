# Motion Design Skill

Motion should communicate hierarchy, continuity, feedback, and atmosphere.

Use:
- entrance/exit choreography
- stagger when useful
- intentional easing
- shared timing relationships
- state transitions
- layout-aware movement

Avoid:
- animating everything
- excessive bounce
- random delays
- repetitive fade-up effects
- motion that blocks interaction

For complex timelines, prefer a dedicated animation timeline rather than many unrelated effects.
