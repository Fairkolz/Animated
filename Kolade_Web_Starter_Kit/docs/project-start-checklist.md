# New Project Start Checklist

- [ ] Create the Next.js/React project.
- [ ] Confirm styling approach.
- [ ] Install only required npm dependencies.
- [ ] Copy selected reusable skills.
- [ ] Copy/adapt AGENTS.md.
- [ ] Define project goals and audience.
- [ ] Define visual direction.
- [ ] Create project-specific design tokens.
- [ ] Identify assets.
- [ ] Define key interactions.
- [ ] Define responsive behavior.
- [ ] Build foundation/components.
- [ ] Build sections.
- [ ] Implement motion.
- [ ] Run visual QA.
- [ ] Run accessibility/performance checks.
- [ ] Deploy.
