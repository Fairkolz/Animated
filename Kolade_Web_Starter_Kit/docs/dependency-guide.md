# Dependency Guide

Typical:
- Next.js + React — application framework
- Tailwind CSS — styling
- Motion — component/UI animation
- GSAP + ScrollTrigger — advanced timelines and scroll-driven motion
- Lenis — smooth scrolling where appropriate
- Three.js / React Three Fiber / Drei — optional 3D/WebGL

Do not install a library because a reference website used it. Install it because the project needs the capability.

Keep npm dependencies project-local.
