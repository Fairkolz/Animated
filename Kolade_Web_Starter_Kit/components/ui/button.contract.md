# Button Contract

Props/behavior:
- variant
- size
- disabled
- loading
- icon
- children
- href/action

States:
- default
- hover
- focus-visible
- active
- disabled
- loading

Implementation:
- semantic `<button>` for actions
- `<a>` for navigation
- visible focus state
- touch-friendly target
- motion respects reduced-motion
- styling comes from semantic design tokens
