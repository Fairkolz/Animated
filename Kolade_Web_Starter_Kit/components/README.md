# Reusable Component Library

Components should be reusable and themeable. They should not contain a specific client's colors or typography.

Recommended base components:
- Button
- Link
- Input
- Select
- Textarea
- Badge
- Card
- Modal
- Accordion
- Tabs
- Tooltip
- Navbar
- Footer
- Section
- Container

Create project-specific compositions on top of these primitives.
