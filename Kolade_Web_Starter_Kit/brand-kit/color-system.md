# Project Color System

Never define colors only by component name such as `blue-button`.

Define semantic roles first.

Example:

- `--color-brand-primary`
- `--color-brand-secondary`
- `--color-surface-background`
- `--color-surface-elevated`
- `--color-text-primary`
- `--color-text-secondary`
- `--color-border-default`
- `--color-accent`
- `--color-success`
- `--color-warning`
- `--color-error`

A component should consume semantic roles. This allows the same component system to work across SaaS, tech, barber, ecommerce, hospitality, or luxury projects.
