# Universal Brand Kit Framework

This is a reusable framework, not a fixed color palette.

Each project should create its own:
- color roles
- typography
- spacing
- radius
- shadows
- motion tokens
- component states

Do not carry a previous client's brand colors into a new project.

Recommended token categories:
- brand
- surface
- text
- border
- accent
- success/warning/error
- typography
- spacing
- radius
- shadow
- motion
