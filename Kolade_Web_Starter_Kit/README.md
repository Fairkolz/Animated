# Kolade Creative Web Starter Kit

A reusable, framework-aware foundation for AI-assisted web development in Antigravity.

## Purpose

This kit separates reusable **creative/development knowledge** from project-specific decisions.

Reusable:
- design thinking
- UI/UX principles
- motion principles
- responsive/accessibility/performance rules
- reusable component contracts
- animation patterns
- brand-token framework

Project-specific:
- brand colors
- typography
- content
- imagery/video/3D assets
- sitemap
- business requirements
- exact motion choreography

## Recommended workflow

1. Create a new project with Next.js/React.
2. Copy only the skills and patterns needed for that project.
3. Copy `AGENTS.md` as a starting point and customize it.
4. Create the project's own design tokens/brand kit.
5. Install project-local npm dependencies such as Motion, GSAP and Lenis when needed.
6. Give Antigravity the project brief and visual references.
7. Ask it to inspect the existing project before changing files.
8. Build in phases and visually QA each major section.

## Important

This repository is intentionally not a finished Next.js application. It is a reusable knowledge/component blueprint.

Agent skills are Markdown instructions; they are not npm packages. Antigravity's exact global/project skill discovery mechanism may differ by version, so place/copy these skill files according to the skill mechanism available in your environment.
