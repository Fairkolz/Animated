# Cinematic Scroll Skill

Use for experiential, narrative pages where scrolling controls a sequence.

Possible techniques:
- GSAP ScrollTrigger
- pinned sections
- scrubbed timelines
- layered parallax
- product/object movement
- scale/rotation transitions
- image/video sequencing
- section-to-section choreography

Before coding, define the timeline as states from 0% to 100% scroll progress.

Do not create cinematic scrolling just for spectacle. Provide a normal-flow or simplified mobile fallback where appropriate.
