# Visual Design Skill

Create deliberate visual hierarchy rather than decorating a generic layout.

Consider:
- composition
- scale
- whitespace
- typography hierarchy
- contrast
- alignment
- rhythm
- focal points
- image/art direction
- brand character

Do not use gradients, glassmorphism, shadows, rounded cards, or decorative effects merely because they are popular. Every visual treatment should support the project's identity and content.
