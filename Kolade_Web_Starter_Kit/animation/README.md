# Animation Pattern Library

Use patterns rather than copying arbitrary animation code.

Recommended patterns:
- reveal
- stagger
- magnetic/interactive hover (only where appropriate)
- page transition
- pinned scroll sequence
- parallax layers
- product travel path
- horizontal scroll section
- image mask reveal

Every pattern should define:
- trigger
- start state
- end state
- timing
- easing
- responsive fallback
- reduced-motion fallback
